# Flick 1.0.4 — UNSIGNED Design Preview

Download **Flick-Setup.exe** from Assets below for a normal Windows installation. Install it over an existing Flick installation; your settings, clip library and videos are kept. A portable ZIP and SHA256SUMS.txt are also included.

This release includes the approved purple design, refined toolbar icons, subtle logo gradients, softer dividing lines and a compact Share panel. It also includes the redesigned clip workspace, optically aligned logo, privacy-preserving Clip Saved banner and confirmed software-update flow.

**This is an unsigned preview, not a Windows-trusted or fully hardware-qualified release.** Smart App Control may block it. GitHub's Latest label identifies the current download; it does not confer publisher trust. Windows 11 x64 with NVIDIA NVENC is the existing capture target. Current physical Windows/GPU acceptance and trusted signing remain pending.

Install this version manually once when upgrading from older builds, including 1.0.3. Subsequent preview updates can be checked through Settings → General → Software Updates, with preview releases enabled. Preview opt-in and explicit unsigned-install consent remain required.

Release publication verifies the exact source, successful Windows CI/render/package runs, installer lifecycle evidence, artifact digest and individual file hashes. SHA-256 checks verify the published bytes; they do not replace code signing.
