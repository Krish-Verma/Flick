# Flick 1.0.9 Preview 1 — UNSIGNED SETTINGS AND UI PREVIEW

Settings saves now preserve remembered audio devices while discovery is loading or a device is disconnected. Refreshes preserve newer selections, and scrolling over closed dropdowns no longer edits preferences. Failed saves retain your edits and point to the relevant field.

The purple interface has clearer spacing, consistent capitalization and shorter copy across Settings, Share, library panels, clip tools, folders and dialogs. Settings keeps navigation and Save/Cancel fixed with one content scroller. Compact Share and clip tools use their available space; linked folders keep long paths in tooltips without a horizontal scrollbar. Existing features remain available.

Install **Flick-Setup.exe** over your existing installation without uninstalling first. Portable users should quit Flick and replace the complete extracted application folder. Your clips and preferences live separately from the program files. Installed preview-enabled copies can check Settings → General → Software updates.

Verification: 497 Core and 9 App tests passed, with 17 explicit opt-in skips; separate generated-media tests passed 8/8 and noncapture checks 20/20. The actual WPF renderer produced 136 reviewed images. Installer upgrade from 1.0.4, parent wait/restart, data retention and uninstall checks passed.

**UNSIGNED PREVIEW:** Windows Smart App Control may block these files. Checksums verify transferred bytes, not publisher identity. Keep Windows security protections enabled. Physical gameplay/GPU/audio/Discord/endurance testing and trusted signing remain separate and are not certified by hosted tests.

Targets Windows 11 x64 with compatible graphics drivers and Microsoft Visual C++ v14 x64 Redistributable. CPU fallback remains optional, limited to 720p/30 FPS, and may affect gameplay performance. Flick remains GPL-2.0-or-later; bundled components retain their notices and corresponding-source obligations.

All previous release entries, statuses, assets and Git tags are retained.
