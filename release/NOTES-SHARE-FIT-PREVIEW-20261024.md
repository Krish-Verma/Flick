# Flick 1.0.7 Preview 1 — UNSIGNED PRODUCT FEATURES PREVIEW

A Windows development preview with recording health and a consented recording test; optional approved-game replay; explicit process-audio choices and nondestructive mixing; clip organization/timeline tools; and a Share presentation with its actions kept visible.

The footer shows simple RAM and CPU readings about once per second. In Settings → General → Display, save “Show RAM and CPU” off to hide the readings and stop optional resource sampling; save it on to resume. No measured memory or CPU overhead improvement is claimed.

Manual replay starts off. Game detection is off by default; explicitly enabled approved-game profiles can start replay when eligible. Microphone recording remains separately opt-in. Missing/ambiguous sources do not silently become desktop or whole-device capture.

Install Flick-Setup.exe over an existing installed preview without uninstalling first. Portable users must quit Flick and retain the complete extracted package. Settings, clip index, originals and imports remain separate from binary replacement. Preview-enabled installed copies can check Settings → General → Software Updates; older versions may require a one-time manual upgrade.

**UNSIGNED:** Smart App Control may block this installer or application. Checksums verify transferred bytes, not publisher identity. Keep Windows security protections enabled. Signing and Store distribution remain separate.

The exact-source hosted build/test/render/installer evidence is linked below. The maintainer is taking real-game/hardware tests separately. Physical game/GPU compatibility, process-audio isolation, microphone/endpoint behavior, Discord transfer, gameplay performance and endurance are not certified by this preview. No trusted-signature, universal-GPU, zero-overhead or leak-free claim is made.

Targets Windows 11 x64 with compatible graphics drivers and Microsoft Visual C++ v14 x64 Redistributable. CPU fallback, if enabled, is limited to 720p/30 fps and may affect game performance. Flick source remains GPL-2.0-or-later; bundled components retain notices and corresponding-source obligations.

All previous release entries, visibility/statuses, assets and Git tags are retained unchanged.
