# Flick 1.0.9 Preview 1 — Settings and UI Cleanup (UNRELEASED · UNSIGNED)

Settings saves now preserve remembered audio devices when discovery is still loading or the devices are disconnected. Saving an unrelated preference no longer requires changing those devices. Device and app refresh also preserve selections made while a refresh is pending. Invalid fields are identified inline; failed saves keep your edits.

The interface retains its purple identity and every feature, with consistent sentence case, shorter labels, less repeated text, one Settings page scroller, and fixed navigation and Save/Cancel actions. Game profiles use a selector. Library filters and clip details open when needed, leaving the virtualized clip list as the steady scroll surface. Share keeps its actions visible; recording, audio, timeline, diagnostics, linked folders, notification and update controls remain available. Scrolling over closed dropdowns no longer changes their selected preferences.

This candidate has not been published. Installers remain unsigned. Actual gameplay, GPU/audio behavior, Discord desktop transfer, endurance and trusted signing are separate from automated UI, settings and installer checks. Windows security protections remain enabled.

When publication is explicitly approved, install Flick-Setup.exe over an existing installation without uninstalling it first. Portable users must quit Flick and replace the complete extracted application folder. Clips and saved preferences remain in their existing user-data locations.

Prior release entries, assets and tags are retained. No source, license or hardware qualification claim is added by this UI fix.
