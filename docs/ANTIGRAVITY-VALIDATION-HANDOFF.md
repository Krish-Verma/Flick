- `System Audio + Microphone` fallback is implemented; independent game/Discord audio capture is not proved.
- WPF `MediaElement` playback of multi-track MKV is unqualified on a clean machine.
- Job Object confinement is fail-closed after process launch, but the microscopic process-start/assignment race has not been eliminated by suspended-process startup.
- Optional Discord webhook mock behavior is distinct from owner-authorized live posting.
- GitHub cloud CI does not replace full system acceptance or an end-user installer test.
