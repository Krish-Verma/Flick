# First-party bug audit and repairs

The owner requested a line-by-line first-party app audit while the monitor/background Replay and hidden-window command fixes were in progress. Independent source reads include App/Core/native, first-party C# helpers and shipping PowerShell/Inno/workflows; generated files and vendored dependencies are excluded. Hash/range coverage and read-only finding records are retained locally under `artifacts/replay-startup-fix-20261030/full-app-audit`. Coverage of changed files is refreshed after the final repair freeze; an audit is not a guarantee that every possible bug has been eliminated.

| ID | Confirmed failure | Repair and regression |
| --- | --- | --- |
| A1 | Failed source settings write changes the displayed/live target and skips recorder transition | Transactional selection/preferences rollback; owned write-failure fixture retains actual source |
| A2 | Late export or thumbnail completion re-adds a removed/unlinked clip | Existing-membership/source-identity conditional updates; held completions, restart index and original-hash checks |
| A3 | Audio-mix local time is mistaken for original clip time | Stable preview-origin snapshot and explicit original seeking; real playhead projection checks |
| A4 | Opt-in recursive cache removal can erase custom originals/exports/imports stored there | Literal app metadata removal and empty-directory-only cache cleanup; nine owned media sentinels |
| A5 | Reused publish staging carries obsolete files into a package | Fresh marker-owned stage; obsolete legacy output excluded and retained |
| A6 | Audio Refresh remains disabled after leaving during discovery | Refresh-request ownership survives page invalidation; held discovery and same-page refresh regression |
| A7 | Originals rescan media work competes with Replay and cannot quiesce on Quit | Propagated cancellation and bounded completion admission; held worker, timeout, retry and settled shutdown checks |
| A8 | Rename ignores Enter | Prompt Save is the default button; other confirmation defaults remain safe |
| A9 | Cancelled thumb drag persists staged trim | Restore committed range and announce revert without a commit; cancelled/successful drag comparison |
| A10 | Depth/directory bounds silently report a complete folder scan | Preserve all bounds and carry explicit traversal-limit flags/reasons; depth-nine and directory-budget fixtures |
| A11 | Reused OBS payload is accepted by filename/architecture despite drift | Pinned archive hash and byte comparison, safe restoration and unknown-code rejection; offline drift/repair fixtures |

An investigated capture/export concurrency path was deliberately withdrawn as a defect: existing functionality allows those operations together. The repair does not add a broad guard that would remove this feature.

Execution evidence is recorded with exact-source Windows CI, media/native checks, rendered views, package lifecycle and the reviewed publication receipt. Authored tests, passing tests, independent source review, public download verification and physical GPU/audio/desktop qualification remain distinct. The owner Windows PC was not reachable over SSH during this repair.
