# R5 — File-first Share

Share opens the contextual panel; it never starts export or sends anything. Local H.264/AAC MP4 export is primary, with 20 MB default, 10/20/50/100/custom 1–250 decimal MB limits, explicit cancellation, progress stages and ready-file fingerprint checks. Copy, file drag and Open Folder remain real Windows actions. Size changes remain blocked during export. Closing the drawer does not cancel a job: reopen Share to inspect progress or cancel it.

Discord direct posting is secondary, collapsed, opt-in and confirmation gated; DPAPI secret storage remains. No OAuth, embedded credentials or automatic sending is introduced. Provider OAuth remains deferred pending a reviewed broker architecture. Physical QA must decode full exported MP4s, verify actual byte caps, edit invalidation and cancellation, and test Discord composer drag/paste without sending.
