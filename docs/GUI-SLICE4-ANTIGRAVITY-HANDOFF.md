3. **Player:** select clips; play/pause, seek with mouse/slider keyboard arrows, media-end reset and full-duration timeline. Test 100 drags/keypresses without index writes on every intermediate motion. Verify visible focus and control of extremely short 0.25-second selections using keyboard/text fields.
