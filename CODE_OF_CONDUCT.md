# Flick Community Code of Conduct

The Flick project aims to be welcoming and technically rigorous. Treat contributors and users respectfully. Discuss technical disagreements with evidence, clear reproduction steps and attention to performance, privacy and accessibility.

Harassment, discriminatory abuse, threats, doxxing and posting other people's recordings or personal information without permission are not acceptable. Reviewers should assume good intent while still requiring accurate tests, provenance and security controls.

Raise conduct concerns privately with the repository maintainers using an appropriate GitHub channel where available; do not disclose private contact information in public issues. Maintainers may moderate issues, discussions and contributions to protect participants.
