Flick 1.0.11-preview.1 — UNRELEASED UNSIGNED replay and UX preview

THIS BUILD IS AN UNQUALIFIED DEVELOPMENT CANDIDATE:
- Targets Windows 11 with a 64-bit x86-64 CPU and working Direct3D 11 graphics.
- Tries available NVIDIA NVENC, AMD AMF and Intel Quick Sync H.264 encoders.
- If allowed and no hardware path starts, CPU compatibility recording uses
  x264 at no more than 1280x720 and 30 fps. It can increase CPU use and reduce
  gameplay performance. You can disable this fallback in Recording settings.
- Encoder availability depends on your exact GPU, drivers and capture setup.

REQUIRED BEFORE RECORDING:
- Current graphics drivers from your GPU or device manufacturer.
- Microsoft Visual C++ v14 x64 Redistributable:
  https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist
  Flick does not automatically download or install this prerequisite.
- All bundled OBS/FFmpeg files must remain with Flick. A self-contained .NET
  build does not remove the separate OBS C++ runtime requirement.

NVIDIA, AMD, Intel, hybrid-GPU and CPU recording paths require physical
Windows acceptance on this exact candidate. Historical RTX 5060 results
and hosted CI for earlier versions are not qualification of this 1.0.11 build.

NOT QUALIFIED:
- Windows on ARM/Snapdragon, 32-bit Windows, macOS and Linux.
- Windows 10 and clean Windows installations without verified prerequisites.
- All games, anti-cheat systems, DRM-protected content and HDR configurations.
Software encoding does not bypass capture restrictions or missing graphics
support. Foreground launches wait for manual replay or an approved game. When Keep
replay ready in the tray is enabled, tray and Windows-startup launches start
your saved source automatically if it is available. Games automation remains
opt-in and records only approved game executables. Stop Replay pauses
automatic replay; Start Replay resumes it. Save is available only when the
buffer is actually ready. Microphone and app-audio opt-ins are unchanged.

Separate App Audio requires supported Windows process-loopback capability
and a current exact process selection. It includes selected process trees,
never silently substitutes whole-device loopback, and stops on source loss.
Microphone capture is a separate opt-in. Attachment is not proof of correct
source isolation. Physical audio/Discord and gameplay performance acceptance
remain pending for this candidate. No leak-free or zero-overhead claim is made.

The browser-downloaded Flick-Setup.exe remains in Downloads until
you delete it manually. Running the setup installs the application in
your chosen location (default %LOCALAPPDATA%\Programs\Flick),
adds a Start Menu shortcut and registers a normal Windows uninstaller.

To remove Flick, choose Uninstall Flick in Settings > General, the
Start Menu shortcut, or Windows Settings > Apps > Installed Apps.
The uninstaller asks separately whether to erase Flick settings/cache,
with NO selected by default. Clips and exports are not removed.

This unreleased candidate is unsigned. Windows Smart App Control may block
it. Checksums verify transfer consistency, not publisher trust; keep Windows
security protections enabled. No public release, trusted signing, Microsoft
Store certification or universal hardware qualification is claimed. Publication requires exact-source verification under the owner's standing
Flick release authorization.
